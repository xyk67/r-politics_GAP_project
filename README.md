# r-politics_GAP_project
This project is about uncovering how “popular” each country is on the political internet forum of r/politics, while establishing how a country’s wealth and population contribute to its popularity. To do so, I employ Ethan Zuckerman's Global Attention Profile model and the subreddit r/politic's naturally occurring data.

To know more about the theoretical background and specific methodologies, visit my website [(https://kooixiuyang.com/investigating-inequalities-in-global-media-attention-on-r-politics/)]
